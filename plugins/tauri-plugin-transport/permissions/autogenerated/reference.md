## Default Permission

Default permissions for the Android transport bridge

#### This default permission set includes the following:

- `allow-list-usb`
- `allow-open-usb`
- `allow-list-spp`
- `allow-open-spp`
- `allow-scan-spp`
- `allow-write`
- `allow-close`
- `allow-register-listener`
- `allow-remove-listener`
